# ABB Azipod Mechanical Parts — PWA

Мобильная PWA-версия исходного руководства ABB Azipod Oy для Arcticaborg / Antarcticaborg.

## Публикация на GitHub Pages
1. Загрузите **всё содержимое этой папки** в корень репозитория.
2. GitHub → Settings → Pages.
3. Source: **Deploy from a branch**.
4. Branch: **main**, folder: **/(root)** → Save.
5. Откройте адрес GitHub Pages на телефоне и добавьте приложение на главный экран.

## Особенности
- 121 страница в исходной последовательности.
- Только вертикальный скроллинг.
- Поиск по доступному текстовому слою документа.
- Кнопка «Скачать офлайн» кэширует все 121 страницы.
- `source-meta.json` содержит SHA-256 исходного DOCX и служебные параметры сборки.
